## ⚡ Technical Architecture

- **Rendering & Math Engine:** MathJax 3.2.2 + KaTeX 0.16.9 hybrid typesetting with optional WebAssembly acceleration.
- **Compute Layer:** Native Web Worker (`worker.js`) executing client-side Monte Carlo simulations, Geometric Brownian Motion (GBM), and VPIN order flow toxicity calculations.
- **Navigation & Telemetry:** ⌘K Spotlight index, live HUD telemetry, and keyboard shortcuts (`/`, `1-9`).
- **Zero Heavy Dependencies:** Pure HTML5, Vanilla CSS3, and modern ECMAScript with sub-50ms global edge delivery via Cloudflare Pages.
